# Realiza Móveis — Website

## Sobre o projeto

Desenvolvi este site para apresentar os móveis da loja Realiza Móveis e facilitar o contato dos clientes com os vendedores. A ideia foi criar uma página responsiva, com fotos e vídeos dos produtos e uma navegação simples.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Three.js (animações e elementos visuais)

## Funcionalidades

- Layout adaptável a celulares e computadores.
- Catálogo de móveis com imagens e vídeos.
- Animações e apresentação visual dos produtos.
- Links de contato pelo WhatsApp.
- Botões preparados para a loja no Mercado Livre. O endereço da loja ainda não foi configurado nesta versão.

## Como executar

É necessário ter Git e Python 3 instalados para seguir os comandos abaixo. Não é necessário instalar dependências de JavaScript.

```bash
git clone https://github.com/brenoschmidt001/realiza-moveis-website.git
cd realiza-moveis-website
python -m http.server 8000
```

Abra http://localhost:8000 no navegador. A biblioteca Three.js e as fontes externas precisam de conexão com a internet. Os links de WhatsApp direcionam ao contato comercial da loja.
